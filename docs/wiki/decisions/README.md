# 架构决策索引

本目录用于索引跨模块的长期架构决策记录（ADR）。当前仓库没有独立 ADR 文件，各类决策按以下归属维护：

- 稳定的长期设计决定直接写在对应的[架构](../architecture/overview.md)或机制规范页面。
- 未关闭的功能缺口与产品范围裁决维护在[客户端功能差异](../../unsupported-client-features.md)与[服务端功能差异](../../unsupported-server-features.md)。
- 已完成决定的演进与变更历史只从 Git 历史查询。

只有当一个跨模块决定无法自然归属单个机制页、且需要长期保留备选方案与后果权衡时，才在本目录增加 ASCII 短横线命名的 ADR 文件并从此索引链接；不得用 ADR 维护进行中的待办状态。
